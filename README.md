# 🧾 Power BI Interactive Sales Dashboard  

## 📊 Project Overview  
This project presents an **interactive Power BI dashboard** designed to analyze retail sales performance using a structured dataset.  
The goal was to uncover key sales insights across multiple dimensions — such as product categories, outlet types, and store locations — by leveraging **Power Query for data cleaning** and **Power BI for dynamic visualization**.

---

## 🧹 Data Cleaning & Transformation (Power Query)  
All data preprocessing was handled in **Power Query**, ensuring clean and consistent data before visualization.  

Key steps included:
- ✅ Removing duplicates and null values  
- ✅ Standardizing column names and data formats  
- ✅ Handling missing entries in product attributes  
- ✅ Creating calculated columns for metrics such as total sales and average ratings  
- ✅ Filtering irrelevant data and reshaping tables for optimized reporting  

These transformations enabled accurate, meaningful analysis within Power BI visuals.  

---

## 📈 Dashboard Features  
The interactive Power BI dashboard provides an intuitive interface for business users to explore and analyze data.  

### Key Visuals Include:
- **Sales Summary** – Displays total sales, number of items, and average ratings  
- **Sales by Item Type** – Compares sales across product categories such as Snacks, Dairy, Fruits & Vegetables, etc.  
- **Sales by Item Fat Content** – Visualizes the distribution between Low Fat and Regular items  
- **Sales by Outlet Type** – Breaks down performance by Supermarkets and Grocery Stores  
- **Sales by Outlet Size** – Compares sales in Small, Medium, and High outlet sizes  
- **Sales by Outlet Location Tier** – Highlights performance based on Tier 1, Tier 2, and Tier 3 cities  
- **Sales Trend by Establishment Year** – Shows growth and consistency over time  

Interactive **filters and slicers** allow users to dynamically view data by category, year, or outlet characteristics.  

---

## 💡 Key Insights  
From the dashboard analysis, several important insights were discovered:  
- 🏬 **Supermarkets** contribute the highest sales share among all outlet types.  
- 🌆 **Tier 3 outlets** outperform other locations in total sales.  
- 📦 **Medium-sized outlets** achieve the highest sales volume.  
- 🍎 **Low Fat items** dominate sales contribution, indicating consumer preference.
